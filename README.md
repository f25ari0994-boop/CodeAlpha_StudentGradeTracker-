# Student Grade Tracker

## Description
This project is a Java-based application that manages student grades and calculates average, highest, and lowest scores.

## Features
- Add student names and grades
- Store multiple students
- Calculate average grade
- Find highest and lowest grades

## Technologies Used
- Java
- ArrayList
- Java Swing (optional GUI version)

## How to Run
1. Compile the program
2. Run the Java file
3. Enter student data in console or GUI
